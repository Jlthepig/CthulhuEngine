# Contributing to Cthulhu

Thanks for your interest and valuable time in contributing to Cthulhu. Every contribution adds another tentacle to the cosmic mythos.

Cthulhu is still in early development, so its architecture and APIs etc. Are changing frequently. Contributions at this time are not possible, for now and the future once contributing becomes possible and encouraged please keep the following in mind.

## Before Contributing

For significant changes, new features, or architectural changes, please open an issue or discussion first.

This helps avoid spending time on work that may conflict with something already planned or currently being developed.

Small bug fixes and improvements can generally be submitted directly.

## Keep Cthulhu Focused

Cthulhu is an engine built **exclusively for first-person shooter games**.

Please avoid introducing systems or abstractions solely to support unrelated game genres. Features should either directly benefit FPS development or improve the engine's underlying architecture.

## Code

When contributing:

- Use C++20.
- Follow the existing code style.
- Keep changes focused and reasonably small.
- Avoid unnecessary abstractions and premature overengineering.
- Prefer fixing the underlying problem rather than adding workarounds.
- Make sure existing functionality still works.

## Pull Requests

When opening a pull request, briefly explain:

- What you changed.
- Why you changed it.
- Any important architectural decisions.
- How you tested it.

Large unrelated changes should be split into separate pull requests where possible.

## Development Status

Cthulhu is a long-term project and is still evolving rapidly.

Expect systems, APIs, and project structure to change as the engine develops.

Thanks for helping make Cthulhu better and feeding the cosmos.
